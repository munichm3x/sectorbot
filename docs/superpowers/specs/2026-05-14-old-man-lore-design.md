# Sector 13 Old Man Lore Bot — Design Spec

**Date:** 2026-05-14  
**Status:** Approved

---

## Overview

A single Discord channel hosts an in-universe SCUM character: "The Old Man of Sector 13". He responds to all messages in that channel, behaves like a legendary old survivor, and never breaks character. Responses are generated by a local Ollama instance; if Ollama is unavailable, a pool of handcrafted fallback lines is used. The feature is entirely self-contained in one file and has zero impact on existing bot functionality.

---

## Architecture

### Approach

Option A — self-contained feature module. All logic lives in `src/features/oldManLore.ts`. The entry point calls `setupOldManLore(client)` once after existing setup, registering a single `messageCreate` listener on the shared Discord.js client.

## Environment Variables

| Variable | Required | Default | Description |
|---|---|---|---|
| `LORE_CHANNEL_ID` | Yes | — | Channel ID where the Old Man responds |
| `OLLAMA_URL` | No | `http://localhost:11434/api/generate` | Ollama API endpoint |
| `OLLAMA_MODEL` | No | `llama3.1:8b` | Ollama model name |

If `LORE_CHANNEL_ID` is missing at startup, `setupOldManLore` logs a warning and returns early — no crash, all existing features continue normally.

## Components

### `setupOldManLore(client: Client): void`

Exported function. Registers one `messageCreate` listener on the provided client. Guard chain:

1. Ignore bots (`message.author.bot`)
2. Ignore messages outside `LORE_CHANNEL_ID`
3. Cooldown check — 5 seconds per user; silently skip if within window
4. Show typing indicator (`channel.sendTyping()`)
5. Update user memory (display name + append message, keep last 5)
6. Detect command prefix (`/story`, `/wisdom`, `/rumor`, `/name`)
7. Build prompt via `buildOldManPrompt`
8. Call `askOllama`; on any failure use `randomFallback()`
9. Reply with `message.reply(response)`

### `buildOldManPrompt(username: string, userMessage: string, memory: UserMemory): string`

Constructs a single string containing:

- **System block**: character identity ("You are The Old Man of Sector 13…"), hard prohibitions (never admit to being AI/bot/program/assistant/language model), tone rules (short sentences, no emojis, no slang, no corporate tone), and theme list
- **Command instruction**: if a command prefix was detected, a one-sentence directive at the top of the prompt (e.g. "Tell a fictional survival story set in Sector 13.")
- **Memory block**: last up to 5 prior messages from this user, labeled by display name
- **Current message**: the user's actual input

### `askOllama(prompt: string): Promise<string>`

- `fetch` POST to `OLLAMA_URL` with body `{ model: OLLAMA_MODEL, prompt, stream: false }`
- 10-second timeout via `AbortController`
- Returns `data.response` trimmed to 1200 characters
- Throws on non-2xx status, network error, or empty response string

### Memory Store

```ts
type UserMemory = {
  displayName: string;
  messages: string[];       // last 5, oldest first
  nickname?: string;        // set by /name command
};

const userMemory = new Map<string, UserMemory>();
```

In-process only — resets on bot restart. No database dependency.

### Cooldown Store

```ts
const cooldowns = new Map<string, number>(); // userId → timestamp ms
const COOLDOWN_MS = 5_000;
```

### Fallback Pool

Array of ~12 static strings, all in-character. Selected via `Math.floor(Math.random() * pool.length)`. Used whenever `askOllama` throws or returns an empty string.

Examples:
- `"The radio is quiet tonight. That is never good."`
- `"I knew a man who asked that once. We found his boots near the northern fence."`
- `"Sector 13 does not answer. It waits."`
- `"Trust is heavier than ammunition. And twice as dangerous."`

### Command Routing

Checked via `message.content.startsWith(prefix)` before prompt construction:

| Prefix | Prompt directive injected |
|---|---|
| `/story` | Tell a fictional survival story set in Sector 13 |
| `/wisdom` | Give one piece of short, dark survival wisdom |
| `/rumor` | Create a dark, believable rumor from this world |
| `/name` | Give this survivor a dark nickname or title, address them by it |
| *(none)* | Answer in character as The Old Man |

## Personality Rules (baked into prompt)

- Never acknowledge being an AI, bot, assistant, program, or language model
- Short sentences. Atmospheric. Melancholic. Paranoid. Calm
- No emojis, no exclamation points, no modern slang, no corporate tone
- Themes: Sector 13, rain, hunger, betrayal, bunkers, dead radios, prison island, black convoys, lost squads, forests, blood, silence, survival
- Maximum response length: 1200 characters (enforced by trim in `askOllama`)

---

## Error Handling

| Scenario | Behaviour |
|---|---|
| `LORE_CHANNEL_ID` not set | Log warning at startup, skip listener registration |
| Ollama not running / unreachable | `askOllama` throws → use fallback |
| Ollama returns empty string | Treated as failure → use fallback |
| Ollama response > 1200 chars | Trim at last space before 1200 boundary |
| `message.reply` fails | Log error, swallow — never crash the process |

---

## Intents Required

`MessageContent` must be added to the client's intent list in `src/client.ts`. Without it, `message.content` is always an empty string on Discord.js v14.

## Out of Scope

- Persistent memory across restarts (no DB for lore)
- Multiple lore channels
- Admin commands to manage the Old Man
- Rate limiting beyond per-user cooldown
